## 👋 Sobre nosotros

**OCR IT Support** es un servicio de soporte técnico informático y desarrollo de herramientas para el sector IT. Creamos aplicaciones prácticas que resuelven problemas reales del día a día: diagnóstico y reparación de Windows, gestión de talleres, automatización de configuraciones de red y utilidades para soporte técnico.

> **Principio de trabajo:** soluciones simples, probadas y sin pasos extra.
